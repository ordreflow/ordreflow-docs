# M2 Core Employee MVP Requirements

Status: **Draft**

These requirements are based on the [M2 milestone](../milestones/M2-core-employee-mvp.md).
The previous M2 user-story draft remains unchanged and is not used as the source
for these requirements.

## Functional Requirements

Functional requirements describe what the users or system must be able to do.
Each requirement is written as a user story. The order is from highest business
priority to lowest business priority. It does not define implementation order;
dependencies such as authentication will be handled when the work is planned.

| ID | Requirement |
| --- | --- |
| `FR-01` | As an employee, I want to register a time entry against an assigned order or task, so that my worked hours can be reviewed. |
| `FR-02` | As an employee, I want to view the orders or tasks assigned to me, so that I know what work I can register time against. |
| `FR-03` | As an employee, I want to view my time entries for a selected week, so that I can review what I registered. |
| `FR-04` | As an employee, I want to view the total time for a selected week, so that I can check my total hours. |
| `FR-05` | As an employee, I want to know why a time entry was returned, so that I can correct and resubmit it. |
| `FR-06` | As an employee, I want to correct a time entry that is still open for changes, so that I can fix mistakes before it is finalized. |
| `FR-07` | As a leader/manager, I want to view time entries for employees in my permitted scope, so that I can inspect them before finalizing them. |
| `FR-08` | As a leader/manager, I want to finalize a time entry, so that it can proceed to export or be returned for correction. |
| `FR-09` | As an authorized user, I want to export accepted time entries for a selected period, so that the company can use the data outside the system. |
| `FR-10` | As a leader/manager, I want to create orders or tasks, so that work can be assigned to employees. |
| `FR-11` | As a leader/manager, I want to assign employees to orders or tasks, so that they can register time on that work. |
| `FR-12` | As an administrator, I want to assign employees to leaders/managers, so that leaders/managers can review the correct time entries. |
| `FR-13` | As an administrator, I want to create user accounts, so that new employees and leaders/managers can access the system. |
| `FR-14` | As an administrator, I want to assign roles to users, so that they receive the permissions needed for their work. |
| `FR-15` | As a pilot user, I want to authenticate with the pilot login, so that I can securely access the features and data available to me. |
