# M0: Inception and Foundation

## Goal

Create a shared understanding of the project and prepare the repositories and technical direction for the first proof of concept.

## Scope

- Confirm the focused MVP direction
- Document the roles of the frontend, backend, and docs repositories
- Document the initial technology stack
- Agree on branching and pull-request practices
- Prepare a reproducible local development environment for the active code repository
- Define the POC goal and acceptance criteria
- Clarify the first API contract and domain terminology

The full MobilOrdre feature set, offline synchronization, advanced administration, and external integrations are outside this milestone.

## Done When

- The repositories have clear READMEs.
- The chosen and open technology decisions are documented.
- The M1 POC scope is agreed by the project group.
- The POC acceptance criteria are written.
- The frontend and backend responsibilities are clear.
- The first API endpoints and data flow are understood.
- The active frontend development environment can be recreated from committed Flox metadata.
