# M2: Core Employee MVP

## Goal

Deliver the first usable employee workflow for registering and reviewing time on assigned work.

## Scope

- Basic authentication
- Employee and admin/leader roles
- Assigned orders or tasks
- Mobile time registration
- Backend validation and authorization
- Editing time entries when allowed
- Personal weekly overview
- Weekly totals
- Clear loading, error, and empty states
- Basic handling of the selected time-entry mode
- Domain/API contract for this Milestone

Administration, reporting, export, approval, and locking can be added in later milestones.

## Done When

- Employees can authenticate through the agreed MVP authentication approach.
- Employees can only access their permitted data.
- Employees can register time on assigned work from a phone.
- Employees can review their weekly registrations.
- Employees can edit entries according to the agreed rules.
- The API enforces validation and authorization independently of the frontend.
- The core employee flow is demonstrated to VS Automatic.
